# Iratu

Iratu is a story led, made to order footwear website for leather shoes made in Kenya.

## First collection

- **Mũthuri** — the woven loafer, the classic character.
- **Mũgendi** — the two tone loafer, the traveller character.
- Both styles are offered in brown and black.
- Price: KSh 4,000 per pair.
- Sizes: EU 39–45.
- Making time is currently estimated at around five days. The final lead time must be confirmed with the maker for each order.

## Ordering setup

Orders are requests via WhatsApp, not automatic payments. Before launch, open `script.js` and set `WHATSAPP_NUMBER` to Iratu's business number in international digits only, with no plus sign or spaces. For Kenya, the number normally starts with `254`.

The customer is told that the order is not confirmed until Iratu confirms the size, production timing, payment and delivery. Do not promise five day delivery until the maker confirms a reliable lead time.

## Run locally

Open `index.html` in a browser. No build step or framework is required.
